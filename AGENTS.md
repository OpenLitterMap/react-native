# AGENTS.md

OpenLitterMap is a React Native mobile app (iOS & Android) for crowdsourced litter
mapping.

**This repository keeps a single source of truth for agent/contributor guidance:
[`CLAUDE.md`](CLAUDE.md). Read it first.**

`CLAUDE.md` covers the project overview, quick start, architecture (navigation,
Redux slices, the upload & tagging model), the API contract, code style, restricted
files, and the **BOOP** release ritual. Everything needed to work in this repo is
there or linked from it (see also [`readme/`](readme/)).

> Maintenance note: do **not** duplicate guidance here — update `CLAUDE.md` and keep
> this file a thin pointer so the two never drift. (This file was previously a stale
> fork several versions behind; hence the pointer.)
