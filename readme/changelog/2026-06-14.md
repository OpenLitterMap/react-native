- v7.11.1 build 91 — Tagging detail-sheet polish (follow-ups to v7.11.0). The top bar (back / progress / `+XP`) now **hides while the keyboard is open**, so its dark overlay no longer covers the search input when the editor rises above the keyboard (keyboard show/hide listeners toggle a `display:none` style — no layout reflow). - v7.11.0 build 90 — **Tagging browse/search rework** (client-only; no API, `/api/tags/all`, or tags-payload change). **Browse** (`CategoryBrowser`) is now a tabbed panel `[ By Category | Most Tagged ]`: By Category is a collapsed accordion (all sections start collapsed) with a pinned synthetic **"All Objects"** section (one row per base object, no category/type variants); type rows are removed from every browse list. Most Tagged is a hardcoded alphabetical fallback pending Pass-2 data (TODO in code). **Type-in-sheet** (`TagDetailSheet`): picking a simple noun routes through the sheet for precision — category auto-resolves when the object is in one category, or the user picks when in several; an optional **Type** section offers the valid `category_object_types` for the (object, category) pair, with **"Skip / Not sure"** = no type (`litter_object_type_id` null). New `SET_TYPE` draft action re-keys the tag in place (preserves quantity/materials/brands/custom; payload shape unchanged). Search-added simple nouns that have types now open the sheet so the type can be set there (type rows were removed from search). **Search** (`TagSearchBar`): replaced the backwards brand-first tie-break with an explicit relevance ladder (exact object → exact compound → starts-with object → … → brand exact/prefix/contains, objects always above brands); brand "contains" matches gated to 4+ character queries; a type/compound row is shown only when a query term matches the type's **own** name (so `can` → base Can, `beer can` → Beer Can); Brands section is collapsible (auto-opens only when there's no strong object match). Detail-sheet section order is now **Quantity → Picked Up → Type → Brands → Materials → Custom Tags**. Bottom-sheet **drag-to-close fixed** (RNGH `ScrollView` + `simultaneousWithExternalGesture` + shared-value scroll position — the Pan was losing the touch to the native scroll). Newly-added tag pills **auto-expand** their inline options (only on a genuine add, not on load/photo-switch). Added 7 i18n keys across all 8 languages.
