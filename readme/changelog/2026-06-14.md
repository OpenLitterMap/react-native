- v7.10.0 build 89 (iOS resubmission) — Fix App Store rejection **ITMS-90683**: re-added `NSPhotoLibraryUsageDescription` to `ios/openlittermap/Info.plist`. It was wrongly dropped in the v7.10.0 photo-picker migration (PHPicker is permission-free at *runtime*, but `react-native-image-picker` + `@lodev09/react-native-exify` statically link PhotoKit symbols, so Apple's binary scan mandates the purpose string regardless). No runtime prompt fires (no `includeExtra` in either picker call). Bumped iOS build only, 88→89 (the rejected delivery was build 88); MARKETING_VERSION stays 7.10.0. Android unchanged (iOS-only fix, no new Android binary). Corrected `readme/MobilePermissions.md` to mark the key as required.
