- v7.11.0 (onboarding) — Onboarding redesign + re-entry. Flow is now a minimal **Welcome** (Begin Tutorial / Skip) → **Enable Location** as a pre-step (step 0; platform-specific iPhone copy, GPS-setup card only) → **Continue Tutorial** starts the 1-2-3 flow at **Select Image** (renamed from "Import image"). New `OnboardingInstructionsScreen`; `StepIndicator` now shows active = solid dot / done = outlined check (so the active marker visibly advances) and supports `currentStep={0}` for the pre-step. **Repeat Tutorial**: restart onboarding from the beginning via the HomeScreen empty-state and a Settings footer pill (`resetOnboarding` action + `useRepeatTutorial` hook). Back navigation moved to a subtle bottom **"Go Back"** button on every onboarding screen (the top-nav chevron was easy to miss). Tidied onboarding screens (removed duplicated welcome content, dead styles) and added/pruned i18n keys across all 8 languages.
