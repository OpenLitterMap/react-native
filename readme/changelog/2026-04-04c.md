## 7.7.1 — 2026-04-04

### Critical fixes (from Claude + Codex audit)
- Fix: quick tags now reset on logout — prevents presets leaking across accounts on shared devices
- Fix: `fetchQuickTags` accepts token override — login/register paths now pass token directly, fixing "No token" rejection on fresh sessions
- Fix: `fetchQuickTags.fulfilled` always replaces presets (empty `[]` clears local) — fixes remote deletions being reversed by sync
- Fix: background fetch race — `locallyEdited` flag prevents server response from overwriting edits made while fetch was in flight
- Fix: `handleIncrement` stale `maxQuantity` closure in TagPills — added to useCallback deps
- Fix: stats persist transform resets `fetchStatus` and `error` to defaults on rehydrate — prevents stale succeeded status on cold boot
- Fix: `useAnimatedCount` cancels animation on unmount + guards setState with mountedRef — prevents React warnings/leaks
- Fix: `useQuickTagsInit` now blocks on `fetchStatus === 'idle'` — prevents seeding defaults before backend fetch starts

### Important fixes
- Fix: TagDetailSheet scroll anchors — keyboard now scrolls to Materials/Brands sections (was scrolling to Quantity/PickedUp)
- Fix: gallery transform imports `initialState` from gallery_reducer instead of hardcoding shape
- Fix: QuickTags chip dead ternary `'white' : 'white'` → `"white"`
- Fix: `isDirty` in useTagDraft compares by length instead of stale reference equality
- Fix: hardcoded English strings in QuickTagsSettingsScreen (`qty`, `material(s)`, `brand(s)`) wrapped in `t()` with plural support
- Fix: TagSearchBar "No results for..." and "Browse categories" wrapped in `t()`
- Fix: `dismissedUris` capped at 500 entries to prevent unbounded growth

### Performance
- `ImpactStat` extracted as `React.memo` component — animation re-renders isolated per stat instead of re-rendering entire YourImpactSection card
- `DraggableRow` wrapped in `React.memo`

### i18n
